# deixis v0.7.0

> **Unreleased draft.** It collects what has landed on `main` since v0.6.0. Before this version is
> tagged, remove this note and confirm every claim against the tagged commit.

A minor release: two exports are new in TypeScript and Go, and the binding vocabulary of
[ADR 0012](../design/0012-data-wire-tree-symmetry.md) is superseded in part by
[ADR 0013](../design/0013-binding-views-and-the-service-line.md).

## No byte or address changed

`deixis-codec-v2` is unchanged since v0.3.0. No encoding and no address differs, and no existing
corpus case changed; the corpus only gained a family (below). The consumer byte-profile name stays
`deixis-codec-v2/identity-bytes@v0.4.0` ([CODEC.md](../CODEC.md) §16). The codec is still a
candidate and is not frozen; [issue #1](https://github.com/Bitspark/deixis/issues/1) tracks the
freeze.

## New: converting a foreign tree to the native node

The codec encodes native nodes only. A tree from another binding, such as bitwire's or bitstore's,
is now copied into the native node by:

- TypeScript: `toNative(tree, limits?)`, with `ToNativeLimits` and the errors `CycleError`,
  `NonconformingTreeError` and `TreeLimitError`;
- Go: `ToNative(tree, limits)`, with the same three error types and `ToNativeLimits`.

A native node is returned unchanged. A tree that is not lawful is refused with `cycle`,
`duplicate_key`, `nonconforming_child` or `limit_exceeded`. [API.md](../API.md) has the details,
ADR 0013 §10 the reasoning. Rust and Python gain no equivalent in this release.

## Changed: the binding vocabulary (ADR 0013)

bitwire 0.4.0 replaced its `Wire` with a duplex envelope connection. In deixis:

- **`WireTree` is no longer a family name.** `DeixisNode<Wire>` named a tree of senders; the
  principal interaction instance is now a receiver-side tree of handlers. `AddressedWire` is gone
  with it. ADR 0012's structural contract is unchanged; its interaction half is superseded.
- Binding portable names to capabilities is ADR 0013 §2. The consumer notes for bitwire and
  bitstore are updated to match.

No deixis export carried either name, so no code changes on upgrading.

## Corpus

A new scripted binding family, `vectors/binding-scripted.json` (19 cases), is replayed by all four
CLIs. The corpus now holds 23 families; each CLI answers 3233 requests. See
[EVIDENCE.md](../EVIDENCE.md).

## Also

- The release workflow's rehearsal no longer fails on the crates loop's exit status (#7).
- The conformance harness builds the Go CLI once per run (#6).
- Development dependencies: TypeScript 7 and `@types/node` 26 in the TypeScript packages; GitHub
  Actions bumped.
